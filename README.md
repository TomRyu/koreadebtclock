# 대한민국 부채시계 (Korea Debt Clock)

[usdebtclock.org](https://www.usdebtclock.org/) 를 대한민국에 맞게 옮긴 실시간 부채시계.
**빌드 도구·서버·API 없는 단일 페이지 정적 사이트**입니다. `index.html` 을 브라우저로 열면 바로 실행됩니다.

```
koreadebtclock/
├─ index.html            ← 본 페이지 (화면 4개를 탭으로 전환)
├─ privacy.html          ← 개인정보처리방침 (애드센스 승인에 필수)
├─ terms.html            ← 이용약관
├─ ads.txt               ← ★ 애드센스 게시자 ID (승인 후 반드시 교체)
├─ robots.txt            ← 애드센스 크롤러 허용 + 사이트맵 위치
├─ sitemap.xml
├─ assets/
│  ├─ css/style.css      ← 계기판 스타일 (흰 판독창 + 컬러 링)
│  └─ js/
│     ├─ core.js         ← 언어 · 통화 · 숫자 포맷 · KST 시간
│     ├─ app.js          ← 렌더링 · 실시간 계산 · 증가율 차트(SVG)
│     ├─ support.js      ← 광고 슬롯 · 쿠키 동의 배너 · 후원 모달
│     └─ legal.js        ← privacy.html · terms.html 공용 렌더러
├─ assets/img/
│  ├─ flag-kr.svg        ← 태극기 (국기법 시행령 규격, 헤더에 사용)
│  └─ flag-kr.png        ← 같은 도형 1800×1200 래스터 (OG·소셜 카드용)
├─ data/
│  ├─ i18n.js            ← ★ 언어 20 · 통화 24 정의 (환율도 여기)

│  ├─ data.js            ← ★ 지표 100여 개 (4개 언어 라벨 포함)
│  ├─ history.js         ← ★ 연도별 시계열 + 정권 데이터
```

## 2. 다국어 20 · 통화 24

**언어와 통화를 분리했습니다.** 독일어로 읽으면서 달러로 볼 수 있습니다.
언어를 고르면 그 언어의 기본 통화가 함께 적용되고, 통화를 직접 바꾼 뒤에는 그 선택이 유지됩니다.

| | |
|---|---|
| **언어 20** | 한국어 · English · 日本語 · 简体 · 繁體 · Español · Português · Français · Deutsch · Italiano · Nederlands · Русский · العربية · हिन्दी · Indonesia · Tiếng Việt · ไทย · Türkçe · Polski · Svenska |
| **통화 24** | KRW USD EUR JPY CNY GBP INR TWD BRL RUB CAD AUD CHF SGD HKD MXN IDR VND THB TRY SAR AED PLN SEK |

정의는 전부 `data/i18n.js` 에 있고, **환율도 이 파일 한 곳**입니다 (`fx` = 이 통화 1단위가 몇 원인가).

### 숫자를 끊는 방식 세 가지

| `group` | 언어 | 축약 | 전체 자릿수 |
|---|---|---|---|
| `cjk` | ko ja zh zt | `1,301조9000억0000만원` | `1,301,900,000,000,000원` |
| `west` | 그 외 14개 | `862,19 Mrd. €` | `862.185.430.464 €` |
| `indic` | hi | `₹79.87LCr` | `₹7,98,71,16,56,44,172` |

만·억·조 표기는 직접 계산하고, 나머지는 `Intl.NumberFormat` 에 맡깁니다.
**통화 기호 위치는 절대 직접 붙이지 마십시오** — `862,19 Mrd. €`(독일) 와 `€ 862,19 mld.`(네덜란드) 처럼
같은 유로도 언어마다 다릅니다. `formatToParts` 로 기호 부분만 꺼내 흐린 span 을 씌우는 방식입니다.

> **기본 표기가 언어마다 다릅니다.** CJK 는 만·억·조가 있어 축약이 기본,
> 나머지 언어는 자릿수가 굴러가는 것이 이 사이트의 본체이므로 전체 자릿수가 기본입니다.
> 사용자가 버튼을 한 번 누르면 그 선택이 언어를 바꿔도 유지됩니다.

### 아랍어 (RTL)

`ar` 은 `dir="rtl"` 로 문서 방향이 뒤집히고, CSS 가 라벨·패널 제목·표를 반대쪽으로 옮깁니다.
**계기판 숫자만은 `direction:ltr` 로 고정**합니다 — 숫자는 아랍어에서도 왼→오른쪽으로 읽습니다.
숫자 자체는 `ar-u-nu-latn` 으로 라틴 숫자를 씁니다. 계기판 폰트(Open Sans)에 아랍 숫자가 없기 때문입니다.

### 번역이 없을 때

`core.js` 의 `pick()` 은 **요청 언어 → `data/labels.js` 오버레이 → 영어 → 한국어** 순으로 내려갑니다.
그래서 번역이 비어도 화면이 깨지지 않고 영어로 보입니다.

선택한 언어와 통화는 `localStorage` 에 저장되고, 처음 방문 시엔 브라우저 언어로 자동 선택됩니다.
딥링크는 `#lang=de` · `#cur=EUR` (`?lang=`, `?cur=` 도 동작).

### 지표 라벨을 더 번역하려면 — `data/labels.js`

`data/data.js` 의 `I(ko, en, ja, zh)` 는 4개 언어만 담습니다.
나머지 16개 언어는 **한국어 원문을 키로 삼는 오버레이**에 넣습니다. `data.js` 를 건드릴 필요가 없습니다.

```js
'국가 부채': X('國家債務', 'Deuda pública', ..., 'Statsskuld'),
//            zt          es                      sv   (16개, 순서 고정)
```

**현재 상태 — 지표 라벨 126개 중 15개(패널 제목 9 + 대형 카운터 6)만 16개 언어로 번역되어 있습니다.**
나머지 111개는 그 언어에서 영어로 표시됩니다. 채우는 만큼 좋아지고, 비어도 깨지지 않습니다.

## 3. 실시간 카운터의 원리

서버에서 데이터를 받아오지 않습니다. 공표된 **기준값**과 **연간 증감액**만 갖고 브라우저가 매 프레임 계산합니다.

```
현재값 = base + rate × (지금 − baseDate) ÷ 1년
```

국가채무가 연 113.3조원 늘면 1초에 약 **359만원**. 그래서 자릿수가 실제로 굴러갑니다.
모든 시각 계산은 **KST(UTC+9) 고정**이라 해외에서 접속해도 "오늘·올해" 경계가 한국 기준입니다.
판독창 폭을 넘치면 숫자 크기를 자동으로 줄입니다.

이 직선을 실제에 가깝게 당기는 장치가 셋 있습니다.

| 장치 | 하는 일 |
|---|---|
| `season` | 1년을 균등하게 쌓지 않습니다. 국세는 부가세 확정신고(1·7월) · 법인세(3월) · 종합소득세(5월)에 몰리므로 월별 가중치로 쌓습니다. 연말 도달값은 균등 배분과 똑같습니다 |
| `anchors` | `data/live.js` 에 최신 월별 공표치가 들어오면 연초 기준값 대신 **그 시점부터** 외삽합니다 |
| 실시간 환율 | 24개 통화 환산이 하드코딩된 값이 아니라 오늘 시세를 씁니다 (7-1장) |

### 무엇이 진짜 실시간이고 무엇이 추정인가 — `freq`

지표마다 근거의 강도가 다릅니다. 국가채무는 월별 공표치 사이를 잇는 보간이고, 국민연금 소진 시점은 30년 뒤 전망입니다.
이걸 시각적으로 똑같이 두면 방문자가 구분할 방법이 없으므로, 셀 라벨 왼쪽에 **작은 점**을 찍고 툴팁에 근거를 글자로 씁니다.

| `freq` | 뜻 | 점 |
|---|---|---|
| `live` | 실시간 (환율 · 올해 경과율) | 초록 |
| `daily` | 매일 갱신 (시장금리 · 지수) | 연두 |
| `monthly` | 월 단위 공표 (재정동향 · 주민등록 인구) | 하늘 |
| `quarterly` | 분기 공표 (GDP · 가계신용) | 노랑 |
| `annual` | 연 1회 공표 | 주황 |
| `budget` | 국회에서 총액이 확정된 예산 | 보라 |
| `legal` | 헌법·법률이 못박은 날짜 — 사이트에서 유일하게 추정이 아닌 값 | 흰색 |
| `projection` | 선형 추정 · 장기 전망 ← **적지 않으면 이것** | 회색 |

패널에 적으면 그 패널의 기본값이 되고, 항목에 적으면 그 항목만 덮어씁니다.
**공표 주기를 모르면 적지 마십시오.** 틀린 배지는 없는 것보다 나쁩니다.

## 4. 숫자 고치는 법 — `data/data.js`

```js
{
  id:   'nationalDebt',                  // derive 에서 v.nationalDebt 로 참조
  l:    I('국가채무 (D1)', 'National Debt (D1)', '国家債務 (D1)', '国家债务 (D1)'),
  s:    I('중앙정부 + 지방정부', 'Central + local', '中央＋地方', '中央＋地方'),
  fmt:  'money',                         // 원화 기준
  c:    'red',                           // 숫자·링 색
  size: 'lg',
  base: 1301.9 * 조,
  rate: 113.3 * 조,
  baseDate: D,
  src:  '기획재정부 2026년 예산'          // 마우스 올리면 툴팁
}
```

### 연간 기준 금액은 상수 `Y` 한 곳에

같은 금액을 여러 지표가 나눠 쓰기 때문에, 파일 맨 위 `Y` 객체에 모아뒀습니다.
**통계가 갱신되면 여기만 고치면 관련 지표가 모두 함께 바뀝니다.**

```js
var Y = {
  debtBase:     1301.9 * 조,   // 국가채무(D1) 잔액        → 2곳
  debtGrowth:    113.3 * 조,   // 국가채무 연간 증가액      → 4곳 (잔액·오늘·1초당)
  debtInterest:   30.5 * 조,   // 국고채 이자              → 4곳 (누적·1인당·1초당·세수대비)
  taxRevenue:      415 * 조,   // 국세 수입                → 3곳
  totalSpend:      728 * 조,   // 정부 총지출              → 2곳
  deficit:         110 * 조,   // 관리재정수지 적자         → 2곳
  d2Base / d2Growth,           // 일반정부 부채(D2) — 적자와 우연히 값이 같을 뿐 별개
  localTax, gdpYear
};
var SEC_PER_YEAR = 365.25 * 86400;
function perSec(yearly) { return yearly / SEC_PER_YEAR; }   // 1초당 값
```

> **함정** — 아래 지표의 보조설명(`s:`)에는 같은 숫자가 **글자로도** 적혀 있습니다.
> `Y` 값을 바꾸면 이 문구도 4개 언어 모두 함께 고치십시오. (`Y` 블록 주석에 목록이 있습니다)
> `올해 국세 수입`("연 415조원 목표") · `올해 정부 총지출`("2026년 예산 728조원") ·
> `올해 국채 이자 지출`("연 30.5조원") · `올해 관리재정수지 적자`("GDP 대비 약 -4.0%")

### 항목 옵션

| 옵션 | 뜻 |
|---|---|
| `yearly: true` | 매년 1월 1일 0시에 0부터 다시 누적 (`base: 0` 과 함께) |
| `daily: true` | 매일 자정에 0부터 다시 누적 |
| `fixed: 값` | 시간에 따라 변하지 않는 값 (금리, 최저임금 등) |
| `text: I(...)` | 숫자가 아닌 표시값 |
| `noconv: true` | 통화 환산 없이 항상 원화로 표시 (예: 원/달러 환율) |
| `compact: true` | 뒤쪽 0 그룹 생략 (`728조 0000억 0000만원` → `728조원`). 딱 떨어지는 고정 금액에만 |
| `derive: fn` | 다른 항목으로 계산 — `function (v) { return v.nationalDebt / v.population; }` |
| `freq: '...'` | 이 값의 근거 종류 (3장 표). 안 적으면 `projection` |
| `season: '키'` | `yearly` 항목의 월별 가중치. `data/data.js` 의 `SEASON` 참조 |
| `until: ...` | 카운트다운 목표 시각. 문자열이거나 `function (now) { return ms; }` |
| `progress: true` | 올해가 몇 % 지났는가 (`fmt: 'pct'` 와 함께) |

`fmt`: `money`(원 기준) · `usd`(달러 기준) · `count`(+`un` 단위) · `pct` · `f1` · `f2` · `text`
   · `until`(`28년 123일`) · `dday`(`D−94일`)
`c`: `red` `green` `blue` `gray` `slate` `mute`

지표 추가는 해당 패널의 `items: [ ... ]` 에 객체 하나 더 넣으면 끝. 레이아웃은 자동으로 늘어납니다.
새 패널은 `panels` 배열에 `{ id, tone, t: I(...), items: [] }` 를 추가하세요.

## 5. 증가율 데이터 — `data/history.js`

* `debt` / `gdp` / `household` — 연말 잔액(조원) 배열 + 시작 연도 `from`
* `lastActual` — 이 연도 이후는 전망치로 표시(반투명 + 범례)
* `admins` — 대통령별 `y0`(취임 직전 연말) → `y1`(임기 마지막 온전한 연말)

증가율·증가액·배율·CAGR은 모두 이 배열에서 **계산**하므로, 숫자만 갱신하면 표와 그래프가 함께 바뀝니다.

> GDP 계열은 한국은행 2020년 기준년 개편 계열입니다. 개편 이전에 발표된 GDP 대비 비율과는 차이가 납니다.

## 7. 이 사이트는 스스로 갱신되지 않습니다

정적 사이트이므로 **아무것도 자동으로 수집하지 않습니다.** 해가 바뀌면 이렇게 됩니다.

| | 연초에 자동으로 |
|---|---|
| `yearly` 누적 카운터 | 0으로 리셋됨 ✅ — 단, **작년 증가율**로 다시 쌓임 ❌ |
| `daily` 카운터 · 시계 · 저작권 연도 | 정상 ✅ |
| `base + rate` 지표 | `baseDate` 기준으로 **무한 선형 연장** ❌ |
| `fixed` 값 (금리 · 최저임금 · 환율 · 출산율) | 그대로 멈춤 ❌ |
| 증가율 그래프 · 남북 비교 · 정권별 표 | 그대로 멈춤 ❌ |

에러가 나지 않고 **그럴듯한 숫자로 조용히 틀려지는** 것이 가장 위험합니다.

### 자동 경고 장치

`meta.fiscalYear` 를 넘긴 해가 되거나 `meta.updated` 로부터 10개월이 지나면
**상단에 빨간 경고 배너가 4개 언어로 자동 노출**됩니다.

> 주의 — 이 화면의 기준 통계는 2026년 자료입니다 (최종 갱신 2026-08-23).
> 그 이후의 확정 통계가 반영되지 않아, 표시되는 값은 당시 증감률을 그대로 연장한 추정치입니다.

갱신을 미루면 방문자가 먼저 알게 되므로, 최소한 **틀린 줄 모르고 인용되는 일**은 막습니다.

### 매년 해야 할 일 (1~2시간)

1. `data/data.js` 의 `Y` 상수 갱신 — 국가채무 잔액·증가액, 국세수입, 총지출, 적자, 국채 이자, GDP
2. `Y` 값이 글자로 박힌 보조설명(`s:`) 4개 언어 함께 수정 (`Y` 블록 주석에 목록 있음)
3. `fixed` 값 갱신 — 최저임금, 출산율, 신용등급
   (기준금리·물가·코스피·국고채금리는 `data/live.js` 의 `ind` 에서, 환율은 봇이 자동으로)
4. `data/history.js` — 각 배열에 확정치 1개씩 추가, `lastActual` 올리기, 정권 `y1` 조정
5. `data/nk.js` — 한국은행 북한 추정치 발표(매년 7월경) 반영, `year` 필드 갱신
5-1. `data/jp.js` — 일본 예산·국채는 12월(정부안)·3월(성립), IMF 수치는 4월·10월에 바뀝니다.
   `data/data.js` 의 `ref:` (부채시계 화면 일본 참조선) 도 같은 값으로 함께 고치십시오
6. `data/live.js` 의 `ind` · `anchors` 확인 (환율은 손대지 마십시오 — 봇이 덮어씁니다)
7. **`meta.updated` 와 `meta.fiscalYear` 갱신** ← 이걸 해야 경고 배너가 사라집니다

## 7-1. 자동 갱신 계층 — `data/live.js`

빌드 도구도 서버도 없는 구조를 지키면서 값을 최신으로 유지하는 층입니다.
`data/live.js` 는 **사람이 아니라 기계가 덮어쓰는 파일**이고, 두 경로로 갱신됩니다.

```
scripts/update-live.js   GitHub Actions 가 매일 07:20 KST 실행 → 바뀌면 커밋
assets/js/live.js        브라우저가 열릴 때 환율만 실시간 fetch (6시간 캐시)
```

둘 다 실패해도 사이트는 파일에 적힌 씨앗값으로 정상 동작합니다.
`file://` 로 열면 fetch 가 CORS 로 막히므로 항상 씨앗값이 쓰입니다 — 이게 정상입니다.

### 왜 환율만 브라우저에서 직접 받는가

환율은 이 사이트에서 **가장 넓게 퍼지는 단일 값**입니다.

- 한국어 사용자를 뺀 모든 방문자가 보는 모든 금액이 여기 걸립니다 (지표 130여 개 × 통화 23개)
- `checkStale()` 이 보는 것은 `meta.updated` 뿐이라 환율은 감시 밖에서 조용히 낡습니다
- 지표 '원/달러 환율' 과 실제 환산이 어긋나면 사이트가 자기모순에 빠집니다

그래서 값을 **한 곳에만** 두었습니다. `data/i18n.js` 의 `fx` 는 마지막 폴백일 뿐이고,
`data/live.js` → `assets/js/live.js` 순으로 덮어씁니다.
`data.js` 의 '원/달러 환율' 항목도 숫자를 적지 않고 `CURRENCIES.USD.fx` 를 읽습니다.
환율 기준일이 45일을 넘기면, 원화 외 통화를 보는 방문자에게 상단 배너가 스스로 알립니다.

### 손으로 돌려보기

```bash
node scripts/update-live.js --dry     # 파일을 안 건드리고 결과만 출력
node scripts/update-live.js           # 환율 갱신

# 월별 확정 공표치를 앵커로 박습니다 (행안부 주민등록 인구통계 등).
# 앵커가 들어오면 연초 기준값 대신 그 시점부터 외삽하므로 오차가 크게 줄어듭니다.
node scripts/update-live.js --anchor population=51234567@2026-08-01

# 한국은행 ECOS 키가 있으면 시장금리도 함께 갱신합니다.
ECOS_API_KEY=... node scripts/update-live.js --dry
```

**앵커에는 반드시 공표 확정치만 넣으십시오.** 사이트가 계산해 보여 준 값을 그대로
되먹이면 추정치가 '확정 공표치' 라벨을 달게 되고, 이후로는 그게 틀렸다는 걸
알아챌 방법이 없어집니다.

값이 상식 밖이거나(원/달러가 500~5000원 밖) 파일 구조가 예상과 다르면 **아무것도 쓰지 않습니다.**
조용히 틀린 값이 들어가는 것이 갱신이 안 되는 것보다 훨씬 위험하기 때문입니다.

### 아직 자동화되지 않은 것

| 대상 | 상태 | 출처 |
|---|---|---|
| 환율 24개 통화 | **자동** | open.er-api → frankfurter (키 불필요) |
| 기준금리 · 국고채 3년/10년 | **구현됨 · 키 필요** | 한국은행 [ECOS OpenAPI](https://ecos.bok.or.kr/api/) (무료) |
| 소비자물가 · 외환보유액 | 통계표 코드 미확인 (`ECOS` 배열의 `on: false`) | 〃 |
| 주민등록 인구 · 세대 (`anchors`) | `--anchor` 로 반자동 | 행정안전부 (공공데이터포털) |
| 코스피 | 수동 (`live.js` 의 `ind`) | — |
| 인구동향 · 취업자 | 수동 | 통계청 [KOSIS OpenAPI](https://kosis.kr/openapi/) |

ECOS 키를 저장소 **Settings → Secrets and variables → Actions** 에 `ECOS_API_KEY` 로
등록하면 워크플로가 금리도 함께 갱신합니다. 키가 없으면 환율만 갱신하고 조용히 넘어갑니다.

`scripts/update-live.js` 의 `ECOS` 배열에 있는 통계표·항목 코드는 **아직 공표 실적과
대조되지 않았습니다.** 켜기 전에 `--dry` 로 먼저 값을 확인하십시오. 특히 소비자물가는
'전년동월비' 표를 써야 하며, 지수(총지수)를 그대로 넣으면 화면에
'소비자물가 상승률 114.2%' 같은 값이 뜹니다.

**재정(예산·세수·국가채무)은 사실상 수동입니다.** 예산은 매년 8~9월 국회 제출 → 12월 확정이라
발표 형식이 해마다 달라져 API로 안정적으로 파싱하기 어렵습니다.

설계 원칙은 하나입니다 — **실패하면 이전 값을 남긴다.** 워크플로가 빨개지는 것보다
낡은 값이 낫고, 낡은 값이 잘못된 값보다 낫습니다. 값마다 상식 범위(`min`/`max`)를 두고
벗어나면 버립니다.

## 9. 남북 비교 — `data/nk.js`

북한은 **국가채무 · 재정 총액 · 조세 통계를 공표하지 않습니다.** 그래서 이 화면은 부채시계가 아니라 규모 비교표입니다.
"북한 부채시계"라는 이름은 쓰지 마십시오 — 뒷받침할 데이터가 없습니다.

행 하나의 구조:

```js
{ l: I('명목 국민총소득 (GNI)', 'Gross National Income', '名目国民総所得', '名义国民总收入'),
  fmt: 'money', year: 2023, south: 2404 * 조, north: 40.2 * 조,
  src: '한국은행 북한 경제성장률 추정' }
```

| 옵션 | 뜻 |
|---|---|
| `year` | 기준 연도. **행마다 다르므로 반드시 표시됩니다** |
| `nobar` | 비율 막대를 그리지 않음 (비율·지수 지표) |
| `diff` | 배율(×) 대신 **차이**로 비교. 비율(%)이나 기대수명처럼 나눗셈이 무의미한 지표에 사용 |

> **원칙** — 성장률·의존도·도시화율 같은 비율끼리 나눠서 "○○배"로 쓰면 통계적으로 틀린 비교입니다.
> 이런 행에는 반드시 `diff: true` 를 주어 `+1.7%p` 형태로 표시하십시오.

북한 수치는 전부 추정치입니다. 특히 한국은행의 북한 GNI는 **북한의 물량 생산을 남한 가격으로 평가한** 값이라
북한 내부의 실제 경제 규모와 다릅니다. 이 경고문이 화면 최상단에 4개 언어로 고정 노출됩니다.
공개 전 [통계청 북한통계포털](https://kosis.kr/bukhan)에서 확정치를 대조하십시오.

## 9-1. 한일 비교 — `data/jp.js`

일본에는 이미 부채시계가 여럿 있습니다 — [財部誠一 借金時計](https://www.takarabe-hrj.co.jp/debtwatch),
[kh-web リアルタイム財政赤字カウンター](http://www.kh-web.org/fin/), 지자체판(茅ヶ崎市 · 夕張市),
영어권 집계 사이트(debtclock.io, global-debt-clock.com) 등.
**그래서 이 화면은 "일본 부채시계"가 아닙니다.** 한국 재정 논쟁에서 가장 많이 인용되는 준거국인
일본을, 한국과 **같은 정의로** 나란히 놓는 비교표입니다.

렌더링은 남북 비교와 같은 코드(`app.js` 의 `buildCmp`)를 씁니다. 새 비교 화면을 붙이려면
`app.js` 의 `CMP` 객체에 항목을 하나 더 넣고, 데이터 파일과 `index.html` 섹션을 만들면 됩니다.

행 하나의 구조:

```js
{ l: I('일반정부 총부채 / GDP', 'General Govt Gross Debt to GDP', '一般政府総債務 / GDP', '一般政府总债务 / GDP'),
  fmt: 'pct', year: 2026, kr: pct(KR.d2, KR.gdp), jp: 204.4, nobar: true, diff: true,
  src: '한국 — 이 사이트의 2026년말 기준값 · 일본 — IMF Fiscal Monitor 2026.4' }
```

> **한국 쪽 값은 직접 적지 마십시오.** `data/data.js` 가 내보내는 `ROK_DATA.Y` 에서 파생됩니다.
> ```js
> var Y = window.ROK_DATA.Y;
> var KR = { debt: Y.debtBase + Y.debtGrowth,  d2: Y.d2Base + Y.d2Growth,
>            gdp:  Y.gdpYear,  pop: Y.popBase + Y.popRate,
>            interest: Y.debtInterest,  spend: Y.totalSpend };
> ```
> 기준 시점은 **2026년말**(기준값 + 연간 증감액)로 통일했습니다. 그래서 `Y` 하나만 고치면
> 부채시계와 한일 비교의 숫자가 함께 움직이고, 두 화면이 어긋날 일이 없습니다.
> 일본 쪽 값만 이 파일에 직접 적습니다.

`nk.js` 와 다른 점만 적으면:

| 옵션 | 뜻 |
|---|---|
| `kr` / `jp` | 왼쪽(한국) · 오른쪽(일본) 값 |
| `bfmt` | **일본 값의 형식.** 생략하면 `fmt` 와 같음. 원화 vs 엔화처럼 같은 행 안에서 통화 기준이 다를 때 씁니다 (`fmt:'money', bfmt:'jpy'`) |
| `fmt:'year'` | 연도. 자릿수를 끊지 않습니다 (2,024년이 되면 안 되므로) |
| `fmt:'text'` | 숫자가 아닌 값. `kr`/`jp` 에 `I()` 를 넣습니다 (현재 쓰는 행은 없습니다) |
| `cmpText` | 배율도 차이도 어울리지 않는 행의 가운데 문구를 직접 지정 (예: "한국이 19년 늦게 도달") |

배율과 막대는 `R.toKrw()` 로 **원화 기준으로 맞춘 뒤** 계산합니다. 그렇게 하지 않으면
1,145조엔과 1,415조원을 그냥 나누는 셈이 됩니다.

### 넣지 않은 행

**10년 국채 금리 · 국가신용등급을 일부러 뺐습니다.** 시장 시세와 등급은 다른 행보다 훨씬 빨리
낡습니다. 갱신을 한 번 놓치면 틀린 숫자가 오래 남고, 그게 이 사이트가 가장 피해야 할 일입니다.
되살리려면 갱신 주기를 함께 정하십시오. 자리는 `data/jp.js` 의 첫 그룹 끝에 주석으로 남겨 두었습니다.

### 이 화면에서 절대 틀리면 안 되는 것 — 정의

> 한국의 **국가채무(D1)** 와 일본에서 흔히 말하는 **「国の借金」** 은 포괄 범위가 다릅니다.
> 그대로 나란히 놓으면 비교가 왜곡됩니다.

그래서 국제비교 행은 **일반정부 총부채(D2 계열)** 로 통일하고,
각국 국내 기준(D1 · 普通国債残高)은 *별도 행*으로 따로 적었습니다.
한국 값은 부채시계와 같은 `Y` 에서, 일본 값은 IMF Fiscal Monitor 에서 옵니다.

주의할 점 두 가지가 화면 상단 경고문에도 4개 언어로 노출됩니다.

1. **IMF 정의 변경** — 2026년 4월 자료부터 일본 총부채가 '비연결 시가' → '연결 액면가' 로 바뀌었습니다.
   그래서 예전에 널리 인용되던 **250% 안팎의 수치와는 이어지지 않습니다** (현재 204.4%, 순부채 134.3%).
2. **환율** — 원화·엔화 금액의 배율은 `data/i18n.js` 의 `JPY.fx` 에 흔들립니다.
   GDP 대비 · 1인당 같은 정규화 지표를 먼저 읽도록 배치했습니다.

### 부채시계 화면의 일본 참조선 (`ref:`)

같은 지표의 일본 값을 부채시계 셀 아래에 `일본 204.4%` 한 줄로 덧붙입니다.
`data/data.js` 의 항목에 `ref` 를 주면 됩니다.

```js
{ l: I('일반정부 부채 / GDP', ...),
  derive: function (v) { return v.d2 / v.gdp * 100; },
  ref: { v: 204.4, s: '일본 참조 — IMF Fiscal Monitor 2026.4 …' } }
```

| 키 | 뜻 |
|---|---|
| `v` | 일본 값 |
| `fmt` | 생략하면 그 지표의 `fmt` 를 따릅니다 |
| `s` | 출처. 셀 툴팁에 원래 `src` 와 함께 붙습니다 |

현재 참조선이 붙은 지표는 6개입니다 — 국가채무/GDP · 일반정부 부채/GDP · 가계부채/GDP ·
국민부담률 · 합계출산율 · 고령인구 비율. **근거 없는 참조선을 붙이지 마십시오.**
`s` 없이 숫자만 띄우면 이 사이트가 지키려는 것을 스스로 깨는 셈입니다.

## 10. 광고(애드센스)와 후원

설정은 전부 **`data/support.js`** 한 파일에 있습니다. 코드는 `assets/js/support.js`.

### 10.1 애드센스 붙이는 순서

1. **먼저 배치만 확인** — `index.html#ads=preview` 를 열면 광고 자리에 회색 자리표시자가 뜹니다. 실제 광고 코드는 삽입되지 않습니다.
2. 도메인 연결 → 사이트 공개 → 애드센스 신청.
3. 승인되면 `data/support.js` 를 고칩니다.

```js
ads: {
  on: true,                            // ← 이걸 켜야 광고 코드가 삽입됩니다
  client: 'ca-pub-실제번호',
  slots: { mid: '실제', growth: '실제', cmp: '실제', foot: '실제' }
}
```

4. 루트 **`ads.txt`** 의 pub 번호도 같은 값으로 교체합니다. 이걸 빼먹으면 애드센스가 "판매자 정보 없음"으로 수익을 제한합니다.

`ads.on` 이 `false` 인 동안에는 `<script>` 도 `<ins>` 도 아예 삽입되지 않습니다. 잘못된 pub ID로 요청이 나가는 일이 없습니다.

### 10.2 광고 자리

| 컨테이너 | 위치 | 보이는 화면 |
|---|---|---|
| `#ad-mid` | 히어로 카운터 **아래**, 패널 위 | 부채시계 |
| `#ad-growth` | 차트 아래 | 증가율 |
| `#ad-cmp` | 비교표 아래 | 남북 비교 |
| `#ad-jp` | 비교표 아래 | 한일 비교 |
| `#ad-foot` | 푸터 위 | 전 화면 |

히어로(대형 카운터) **위에는 광고를 두지 않습니다.** 이 사이트의 핵심 콘텐츠를 접히는 선 아래로 밀어내는 배치는 애드센스 정책에서도 문제가 되고, 사이트의 인상도 망칩니다.

광고 상자는 판독창(`.readout`)과 **일부러 다르게** 생겼습니다. 컬러 링 없이 점선 테두리에 `광고` 라벨을 붙였습니다. 계기판처럼 보이는 광고는 "콘텐츠와 혼동되는 배치"로 정책 위반입니다.

숨겨진 탭에서 `push()` 하면 폭이 0으로 잡혀 빈 광고가 되므로, `support.js` 는 **실제로 보이는 슬롯만 한 번씩** 채웁니다. 탭을 바꾸면 `app.js` 의 `setView()` 가 `RDCSupport.refresh()` 를 불러 나머지를 채웁니다.

### 10.3 쿠키 동의

```js
consent: { mode: 'builtin' }   // 'builtin' | 'google' | 'off'
```

* `builtin` — 내장 배너. **동의**하면 맞춤 광고, **거부**하면 `requestNonPersonalizedAds = 1` 로 비맞춤 광고가 나갑니다. 거부해도 광고가 사라지지는 않으므로 수익이 0이 되지는 않습니다.
* `google` — 애드센스 콘솔의 *개인정보 보호 및 메시지*(Funding Choices) CMP 를 쓸 때. 내장 배너는 뜨지 않습니다.
* `off` — 배너 없이 바로 맞춤 광고.

> **EEA·영국 트래픽이 있다면 `google` 을 쓰십시오.** 구글은 해당 지역에 대해 *구글이 인증한 CMP* 사용을 요구하며, 내장 배너는 인증 대상이 아닙니다. 내장 배너는 그 외 지역과 승인 전 단계를 위한 것입니다.

### 10.4 후원

```js
support: {
  links: [ { on: true, id: 'toss', langs: ['ko'], url: 'https://toss.me/...' }, ... ],
  bank:  { on: false, ... }
}
```

* `on: false` 면 표시되지 않고, `langs` 를 지정하면 해당 언어에서만 보입니다 (토스·카카오페이는 `['ko']`).
* 헤더의 **후원하기** 버튼과 푸터 링크, `index.html#support` 딥링크가 모두 같은 모달을 엽니다.

**법적으로 유지해야 할 것 두 가지**

1. `기부금`이 아니라 **`후원`** 으로 표기합니다. 「기부금품의 모집 및 사용에 관한 법률」상 1천만원 이상 모집은 사전 등록이 필요하고, 기부금영수증은 지정기부금단체만 발급할 수 있습니다.
2. `support.note` (대가성 없음 · 영수증 미발급 · 결제정보 미보유)를 지우지 마십시오. 모달 하단에 항상 표시됩니다.

### 10.5 광고와 후원을 같이 받는 것에 대해

모순이 아닙니다. 다만 **푸터의 "비영리 정보 제공" 문구는 모순이라 삭제**했고, `core.js` 의 `funding` 문구(`광고와 후원으로 운영되는 독립 사이트`)로 바꿨습니다. 광고 수익이 발생하는 사이트를 비영리라고 표기하면 애드센스 정책 이전에 표시광고법상 문제가 됩니다.

후원 모달에는 `support.why` 문구로 **"후원해도 광고는 사라지지 않는다"** 는 점을 먼저 밝힙니다. 로그인이 없는 정적 사이트라 방문자별로 광고를 끌 수 없기 때문이고, 이를 감추면 후원자가 배신감을 느낍니다.

### 10.6 방침·약관 문서

`privacy.html` · `terms.html` 은 `data/legal.js` 의 4개 언어 본문을 읽어 그립니다. 본문 안의 `{site}` `{contact}` `{date}` 는 `data/support.js` 의 값으로 치환됩니다.

**애드센스 신청 전에 반드시 교체할 값** — `data/support.js` 의 `site`, `contact`, `operator`, `effective`. 연락 가능한 이메일이 없으면 심사에서 반려됩니다.
